# 生鲜售后 Agent 前端设计规划（含全栈目录）

> 配套文档：PRD_生鲜售后agent.md
> 日期：2026-09-30

## 一、页面清单与跳转逻辑

按 PRD 拆成"消费者体验台 + 运营后台"两套视图，共 7 个页面（不含登录，个人项目不做登录）。跳转关系如下：

```
顶栏 Logo ──────────────────────────► /chat 对话体验台
侧边栏（分组）
  ├─ 演示
  │   └─ 对话体验台 /chat
  └─ 运营
      ├─ 概览 /overview（P2 可选）
      ├─ 工单中心 /tickets
      ├─ 评测中心 /evals
      ├─ 监控中心 /traces
      ├─ 知识库 /knowledge
      └─ 意图模型 /intent
```

**01 对话体验台（核心页）**
三栏布局：左侧会话列表，中间对话区，右侧详情抽屉（默认收起）。

- 顶部"新建会话" → 创建 session 并清空对话区
- 消息里"工具调用"卡片点击 → 右侧抽屉展开该次调用的入参/出参/耗时
- 消息里"查看 Trace"链接 → 跳转 /traces/:traceId（监控中心详情）
- 输入框旁"转人工"按钮 → 弹出确认框 → 调用创建工单 → 跳转 /tickets/:ticketId
- 左侧会话列表点击某会话 → /chat/:sessionId 加载历史消息
- 消息内"当前意图/已填槽位"徽标点击 → 右侧抽屉查看会话状态

**02 工单中心**
- 列表页：状态筛选（待处理/处理中/已关闭）、列表行点击 → 详情页 /tickets/:id
- 详情页：工单信息、关联订单、对话上下文摘要；"查看原始对话" → /chat/:sessionId 回放

**03 评测中心**
- 数据集页：数据集卡片列表 → 点击进入样本列表；样本行点击 → 右侧抽屉看标注详情
- 发起评测 → 跳转 /evals/runs/:runId（运行中显示进度）
- 完成后 → 报告页：分层指标卡片 + 与上一版本的对比表

**04 监控中心**
- 概览区：核心指标卡（达成率、转人工率、P95 延迟、失败分类占比）
- Trace 列表：行点击 → /traces/:traceId
- Trace 详情：span 树 + 每个节点的输入输出；"关联会话" → /chat/:sessionId

**05 知识库**
- 文档列表：行点击 → 右侧抽屉预览；"上传" → 上传弹窗（选择文件 + 索引状态）
- 每行显示：文档名、分类、分块数、更新时间、索引状态标签

**06 意图模型**
- 版本列表：版本号、训练状态、F1/时延/成本三列指标
- 勾选两个版本 → "对比" → 对比视图（指标差异高亮）
- "发起训练" → 训练任务弹窗 → 列表内显示进度

**07 概览（P2）**
- 四个指标卡 + 近 7 天趋势图，点击指标卡 → 跳到对应模块

## 二、设计风格与字体

**整体风格**：干净、克制、专业的运营后台风。白底 + 灰阶中性色 + 单一品牌色，不用渐变、不用装饰插画、不用 emoji。

**色板**：

| 用途 | 色值 |
| --- | --- |
| 品牌主色（生鲜青绿） | #16A34A |
| 主色 hover | #15803D |
| 主色浅底（标签/选中态） | #F0FDF4 |
| 页面背景 | #F8FAFC |
| 卡片/面板 | #FFFFFF |
| 边框 | #E5E7EB |
| 主文字 | #0F172A |
| 次文字 | #475569 |
| 弱文字 | #94A3B8 |
| 成功/失败/警告 | #16A34A / #DC2626 / #D97706 |
| 信息（工具调用等） | #2563EB |

**字体**：

- 中文 UI：系统字体栈（PingFang SC、Microsoft YaHei、Noto Sans SC），不额外下载字体，保证加载性能
- 数字与指标：同一字体栈 + `tabular-nums`（等宽数字，表格对齐）
- 订单号、trace id、代码：等宽字体栈（SF Mono / JetBrains Mono 降级）
- 字号阶梯：12 / 13 / 14 / 16 / 20 / 24，正文 14px、行高 1.5

**组件规范**：卡片圆角 8px、按钮/输入框 6px、弹窗 12px；间距以 4px 为基数（4/8/12/16/24/32）；阴影只用一层轻投影；图标统一用 lucide-react 线框风格。

## 三、Vite 构建方案

- 技术栈：Vite + React + TypeScript + React Router + Tailwind CSS + zustand
- 组件：Radix primitives 为底封装自己的轻量组件库；图表用 ECharts；消息区 Markdown 用 react-markdown
- 请求：axios 封装 + SSE/流式读取（对话流式输出）
- vite.config：别名 `@` → `src`；dev 代理 `/api` 和 `/ws` 到 FastAPI
- 环境变量：`.env.development` 放 `VITE_API_BASE_URL`、`VITE_WS_URL`
- 脚本：`dev` / `build` / `preview`；产物输出 `dist/`

## 五、整洁美观原则

- 每个页面最多三档视觉层级：标题 → 卡片/内容 → 辅助信息，不堆叠装饰
- 空状态统一用"一句话说明 + 动作按钮"，不用表情和插画
- 表格：表头浅灰底、行 hover 高亮、数字列右对齐等宽
- 状态一律用色点 + 文字标签（如"已关闭"），颜色只表达状态语义
- 图标只出现在可点击元素旁，纯装饰图标一律不加
- 所有文案统一时态和称谓，不混用"您/你"

## 六、交互细节清单

- 可点击元素统一 `cursor: pointer`；禁用态 `cursor: not-allowed` 且不响应 hover
- 按钮、链接、列表行 hover 有 150ms 过渡；输入框 focus 边框变主色，键盘焦点有 2px 可见 outline
- 长文本（文档名、订单号、消息摘录）单行省略，hover 显示 Tooltip
- 图标按钮必须带 aria-label，保证键盘可达
- 发送消息：Enter 发送、Shift+Enter 换行；发送期间输入框禁用并显示"生成中"
- 表格表头 sticky；加载态用 Skeleton 而不是转圈；Toast 3 秒自动消失；危险操作（转人工、删除）必须二次确认 Modal
- 流式输出：消息逐字渲染，底部保持"正在输入"状态，自动滚动到底部但用户上翻时不打断
- 全部无 emoji、无动效装饰，动画只用于状态反馈（淡入、抽屉滑出）

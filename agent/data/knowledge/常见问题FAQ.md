# 常见问题 FAQ

> 来源：《生鲜售后常见问题（示例整理）》，仅用于本项目演示，不代表任何真实平台的正式答复。

## 1. 订单与物流

1. 问：我的订单到哪了？答：提供订单号即可查询订单状态与物流节点。
2. 问：多久能发货？答：生鲜订单一般在支付后 24 小时内发货，节假日顺延。
3. 问：可以修改收货地址吗？答：未发货订单可尝试修改，已发货订单需与快递协商。
4. 问：显示签收但我没收到？答：请先确认门卫或快递柜，仍未找到可转人工核实。
5. 问：可以指定送达时间吗？答：生鲜订单不支持精确到小时的预约配送。

## 2. 品质与赔付

1. 问：草莓坏了一半怎么赔？答：坏果 50% 按订单金额的 50% 赔付，需提供照片或文字凭证。
2. 问：坏了一点点可以赔吗？答：坏果低于 10% 不进入赔付流程，可申请优惠券补偿。
3. 问：照片传不上来怎么办？答：可用文字描述坏果比例，记为文字凭证后正常提交工单。
4. 问：多久能拿到赔付？答：自动审核工单一般 2 小时内完成，退款 1 至 3 个工作日到账。
5. 问：为什么只能赔一半？答：赔付档位按坏果比例匹配，超出档位的诉求需要人工确认。
6. 问：不想要优惠券，能直接退钱吗？答：低比例瑕疵默认补偿优惠券，如不接受可转人工协商。

## 3. 退款与发票

1. 问：退款多久到账？答：审核通过后 1 至 3 个工作日原路退回。
2. 问：退款失败怎么办？答：提供工单号由客服查询支付渠道状态。
3. 问：怎么开发票？答：订单详情页申请开票，电子发票 24 小时内发送至邮箱。
4. 问：发票抬头写错了怎么办？答：可申请作废重开，需提供正确抬头与税号。

## 4. 商品与储存

1. 问：车厘子怎么保存？答：冷藏 0 至 4 度，食用前再清洗，建议 3 天内吃完。
2. 问：香蕉放冰箱可以吗？答：不建议，低温会加速表皮变黑，常温阴凉处存放即可。
3. 问：叶菜怎么保鲜？答：用厨房纸包裹后装保鲜袋冷藏，可延长 2 至 3 天。
4. 问：冷冻肉能放多久？答：零下 18 度冷冻建议 3 个月内食用完。

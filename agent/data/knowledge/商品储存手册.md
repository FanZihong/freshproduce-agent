# 商品储存手册

> 来源：《生鲜商品储存与食用建议（示例整理）》，仅用于本项目演示，不代表权威食品安全结论。

## 1. 浆果类

1. 草莓、蓝莓、树莓建议冷藏 0 至 4 度保存，食用前再清洗。
2. 浆果类尽量 2 至 3 天内食用完，出现霉点的整盒不建议继续食用。
3. 清洗后的浆果需沥干水分再冷藏，避免加速腐烂。

## 2. 热带水果

1. 香蕉、芒果、火龙果适合常温阴凉处存放，不建议冷藏。
2. 未成熟的牛油果可常温催熟，变软后冷藏并在 2 天内食用。
3. 榴莲开壳后需密封冷藏，建议 24 小时内食用完。

## 3. 叶菜与根茎

1. 叶菜用厨房纸包裹后装保鲜袋冷藏，可延长 2 至 3 天。
2. 土豆、洋葱、南瓜适合阴凉干燥处存放，避免阳光直射。
3. 土豆发芽或表皮大面积变绿后不建议食用。
4. 胡萝卜、白萝卜去掉叶子后冷藏，可存放 1 周左右。

## 4. 肉禽蛋与水产

1. 冷鲜肉建议冷藏 0 至 4 度并在 2 天内食用完。
2. 冷冻肉在零下 18 度条件下建议 3 个月内食用完，避免反复解冻。
3. 鸡蛋冷藏保存，食用前无需清洗蛋壳，避免破坏保护膜。
4. 活鲜建议当天烹饪，冰鲜水产冷藏不超过 24 小时。

## 5. 食用安全提示

1. 出现明显异味、黏液或大面积霉变的商品请勿食用。
2. 生熟食材需分开存放与处理，避免交叉污染。
3. 商品解冻后不建议再次冷冻，口感与安全性都会下降。

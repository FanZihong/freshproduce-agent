# 生鲜售后政策总则

> 来源：《生鲜电商售后服务政策（示例整理）》，仅用于本项目演示，不代表任何真实平台规则。

## 1. 受理范围

1. 本政策适用于生鲜果蔬、肉禽蛋、水产等品类的售后咨询与赔付申请。
2. 已签收订单出现品质问题的，按品类与问题类型分别处理。
3. 未发货订单的取消与退款按取消政策执行，不在品质赔付范围内。
4. 超过 48 小时提出的品质问题需人工判断时效责任。

## 2. 退款与退货

1. 生鲜商品因保质期短，原则上不支持无理由退货，质量问题按赔付处理而非退货。
2. 退款审核通过后一般 1 至 3 个工作日原路返回。
3. 超过 3 个工作日未到账的，可提供工单号由客服查询银行处理进度。
4. 一次性全额赔付的订单不支持再次申请品质问题。
5. 使用优惠券支付的部分按券的规则退回或作废，以活动说明为准。

## 3. 工单与时效

1. 自动受理的赔付工单一般在 2 小时内完成审核。
2. 需要人工核实的工单在 24 小时内给出处理结论。
3. 工单状态分为待处理、处理中、已关闭三种，用户可在工单中心查看。
4. 工单关闭后如有新证据，可联系客服重新开启。

## 4. 转人工规则

1. 用户明确要求人工客服的，立即转人工并同步对话上下文。
2. 用户情绪激烈或提出投诉、差评、曝光等诉求的，升级为高优先级工单。
3. 连续三轮未能获取有效信息的，系统自动转人工，避免无效循环。
4. 涉及金额争议、异物理赔、账号风险的，必须人工处理。

## 5. 隐私与合规

1. 手机号、收货地址等个人信息在长期记忆中做脱敏处理。
2. 对话记录仅用于售后处理与服务质量分析，不对外提供。
3. 用户可要求删除个人对话记录，删除后仅保留脱敏统计信息。

## 补充问答

1. 问：临期商品能退吗？答：临期特惠商品在下单页会标注保质期与建议食用时间，因已明确告知，不支持以「快到期」为由退货；出现变质、异味等品质问题的，仍按品质赔付标准处理。
2. 问：预售商品的售后怎么算？答：预售商品未发货前可申请取消并全额退款；发货后按普通订单处理，品质申诉期以实际签收时间起算 48 小时。
3. 问：售后的工单多久会自动关闭？答：工单状态分为待处理、处理中、已关闭三种；需要人工核实的工单在 24 小时内给出结论，长期未补充凭证的工单会由系统关闭并在会话中提示，具体时限以工单中心页面为准。
4. 问：拆封的水果能退吗？答：生鲜商品因保质期短，拆封后不支持无理由退货；出现变质、坏果等品质问题，按赔付标准处理而非退货。

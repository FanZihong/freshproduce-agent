# 物流时效说明

> 来源：《生鲜配送时效与异常处理（示例整理）》，仅用于本项目演示，不代表任何真实平台的时效承诺。

## 1. 配送时效

1. 同城生鲜订单一般当日或次日达，具体以订单页面承诺时效为准。
2. 跨城生鲜订单一般 48 至 72 小时送达，全程冷链运输。
3. 遇雨雪、台风等极端天气，时效顺延，系统会在订单页提示。
4. 节假日期间的订单按公告时效执行，可能延长 1 至 2 天。

## 2. 签收规则

1. 生鲜订单默认支持本人签收与快递柜代收两种方式。
2. 显示已签收但用户未收到的，优先排查快递柜、门卫与家人代收。
3. 超时未取件导致商品变质的，责任由用户承担，不在赔付范围。
4. 生鲜订单不支持修改配送方式为自提点二次转运。

## 3. 物流异常处理

1. 物流信息超过 24 小时无更新的，可提交催单，客服会联系承运方核实。
2. 订单已发货但超过承诺时效未送达的，可申请时效补偿。
3. 包裹破损或外包装明显挤压的，建议当面拒收并拍照留存。
4. 无物流记录但订单显示已发货的，转人工核实承运单号。

## 4. 催单与补偿

1. 催单后 12 小时内无进展的，升级为高优先级并转人工跟进。
2. 时效超期补偿标准为订单金额的 10%，单笔最高 20 元。
3. 因物流延误导致的商品变质，按品质赔付标准执行，不与时效补偿叠加。

# 生鲜赔付标准表

> 来源：《生鲜售后赔付标准（示例整理）》，仅用于本项目演示，不代表任何真实平台的现行规则。

## 1. 通用原则

1. 生鲜商品支持签收后 48 小时内提出品质问题，超时需人工审核是否受理。
2. 赔付以订单实付金额为基数计算，不含优惠券、运费险与平台补贴部分。
3. 同一订单同一问题只赔付一次，重复申请会被系统拦截并提示已有工单。
4. 商品已食用、已丢弃或无法提供任何凭证的，需转人工核实后再决定是否赔付。
5. 用户对赔付结果有异议、或明确要求全额赔付时，一律转人工处理。

## 2. 坏果与破损赔付档位

1. 坏果比例低于 10%：不进入赔付流程，以安抚为主，可补偿一张 5 元优惠券。
2. 坏果比例 10% 至 30%：按订单实付金额的 20% 赔付。
3. 坏果比例 30% 至 50%：按订单实付金额的 50% 赔付。
4. 坏果比例 50% 至 80%：按订单实付金额的 80% 赔付。
5. 坏果比例超过 80%：按订单实付金额全额赔付。
6. 赔付金额超过 200 元时不再自动审核，必须转人工确认后执行。
7. 单笔订单自动赔付上限为 200 元，跨订单累计赔付上限为 500 元。

## 3. 缺斤少两赔付

1. 实际重量低于标注重量 5% 以内：以补偿优惠券为主，不做现金赔付。
2. 实际重量低于标注重量 5% 至 15%：按缺重比例对应金额的两倍赔付。
3. 实际重量低于标注重量 15% 以上：全额赔付并记录商家违规。
4. 重量争议需要用户提供带包装的称重照片，照片需能看清电子秤读数。
5. 无称重凭证的重量申诉，转人工核实后再判断。

## 4. 特殊情形

1. 商品发霉、有异味、明显变质：不受比例限制，直接按全额赔付处理。
2. 商品内出现异物：立即转人工，不做自动赔付，避免二次风险。
3. 冰袋融化但商品完好：不构成赔付条件，可说明情况并安抚。
4. 商品与描述严重不符（如品种发错）：按全额赔付或补发处理，由人工确认。
5. 因用户填错地址、超时未取件导致的变质，不属于赔付范围。

## 5. 凭证要求

1. 照片凭证需包含商品主体与包装标签，能确认是本订单商品。
2. 若照片无法上传，可用文字描述坏果比例与现象，并记录为"文字描述（无照片）"。
3. 凭证不足但情况合理的，按最低档位赔付并提交工单备注。
4. 伪造凭证一经发现，取消本次赔付并标记账号风险。

## 补充问答

1. 问：赠品坏了能赔吗？答：赠品与试吃装随主订单发出，出现变质或破损的，可申请补发同类赠品，或按赠品价值补偿优惠券；赠品不单独计算赔付金额，也不影响主商品的品质赔付。
2. 问：水果切开发现里面有虫能赔吗？答：切开后发现的内部虫蛀、霉变按品质问题处理：请保留实物并拍摄切面照片，由人工核实后按全额或高比例赔付；涉及异物或食品安全风险的转人工，不做自动赔付。

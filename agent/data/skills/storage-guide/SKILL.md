# 生鲜储存建议

## 按品类回答

- **浆果（草莓/蓝莓/树莓/车厘子）**：冷藏 0–4℃，食用前再洗；2–3 天内吃完，出现霉点整盒不建议继续吃。
- **热带水果（香蕉/芒果/火龙果）**：常温阴凉处，不建议冷藏；牛油果未熟常温催熟，变软后冷藏 2 天内吃完；榴莲开壳后密封冷藏 24 小时内吃完。
- **叶菜**：厨房纸包裹后装保鲜袋冷藏，可延长 2–3 天。
- **根茎（土豆/洋葱/南瓜）**：阴凉干燥、避免阳光直射；土豆发芽或大面积变绿不要吃；萝卜去叶后冷藏约 1 周。
- **肉禽蛋水产**：冷鲜肉 0–4℃、2 天内吃完；冷冻肉 -18℃、3 个月内吃完且不要反复解冻；鸡蛋冷藏、食用前不清洗蛋壳；活鲜当天烹饪，冰鲜水产冷藏不超过 24 小时。

## 安全提示

明显异味、黏液、大面积霉变的商品不要食用；生熟分开；解冻后不建议再次冷冻。

## 边界

储存建议不等于食品安全结论；用户已经食用且身体不适时，建议就医并转人工记录。

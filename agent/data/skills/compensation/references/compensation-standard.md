# 生鲜赔付标准（节选）

> 来源：《生鲜售后赔付标准（示例整理）》；仅用于本项目演示，不代表真实平台规则。

## 赔付档位

| 坏果比例 | 赔付比例 |
| --- | --- |
| 低于 10% | 不进入赔付流程，补偿 5 元优惠券 |
| 10% 至 30% | 按订单实付金额 20% |
| 30% 至 50% | 按订单实付金额 50% |
| 50% 至 80% | 按订单实付金额 80% |
| 超过 80% | 全额赔付 |

单笔自动赔付上限 200 元，跨订单累计上限 500 元；超过 200 元必须转人工确认。

## 缺斤少两

1. 实际重量低于标注 5% 以内：以优惠券补偿为主，不做现金赔付。
2. 低于标注 5% 至 15%：按缺重比例对应金额的两倍赔付。
3. 低于标注 15% 以上：全额赔付并记录商家违规。
4. 重量争议需提供带包装的称重照片，能看清电子秤读数；无凭证转人工。

## 特殊情形

1. 发霉、异味、明显变质：不受比例限制，直接按全额赔付处理。
2. 商品内有异物：立即转人工，不做自动赔付。
3. 冰袋融化但商品完好：不构成赔付条件，说明并安抚。
4. 品种发错等与描述严重不符：全额赔付或补发，由人工确认。
5. 用户填错地址、超时未取件导致变质：不属于赔付范围。

## 凭证要求

照片需包含商品主体与包装标签；无法上传时可用文字描述比例与现象，记为"文字描述（无照片）"；伪造凭证取消赔付并标记账号风险。

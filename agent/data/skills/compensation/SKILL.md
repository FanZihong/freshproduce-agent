# 坏果与缺斤少两赔付

## 计算基数

赔付以**订单实付金额**为基数，不含优惠券、运费险与平台补贴；同一订单同一问题只赔一次。

## 坏果档位

| 坏果比例 | 赔付 |
| --- | --- |
| < 10% | 不进入赔付，安抚 + 5 元优惠券 |
| 10%–30% | 实付金额 20% |
| 30%–50% | 实付金额 50% |
| 50%–80% | 实付金额 80% |
| > 80% | 全额赔付 |

单笔自动赔付上限 200 元；赔付金额超过 200 元必须转人工确认。

## 缺斤少两

- 缺重 ≤ 5%：以优惠券补偿为主，不做现金赔付。
- 缺重 5%–15%：按缺重对应金额的 **2 倍**赔付。
- 缺重 > 15%：全额赔付，并记录商家违规。
- 重量争议需要带包装的称重照片（能看清电子秤读数）；无凭证转人工。

## 必须转人工

商品内有异物、与描述严重不符、用户对赔付结果有异议、要求全额赔付、凭证无法核实时。

## 凭证

照片需包含商品主体与包装标签；无法上传时用文字描述比例与现象，记为"文字描述（无照片）"。

## 细则

用户追问具体档位、上限、特殊情形时，再读 `references/compensation-standard.md`。

# 物流时效与异常

## 时效口径

- 同城：当日或次日达；跨城：48–72 小时，全程冷链。
- 极端天气、节假日顺延，以订单页承诺与公告为准。
- 支付后一般 24 小时内发货，节假日顺延。

## 显示签收但没收到

先排查快递柜、门卫、家人代收；仍未找到转人工核实，不要直接承诺赔付。

## 物流不更新 / 催单

- 超过 24 小时无更新：提交催单，客服联系承运方。
- 催单后 12 小时仍无进展：升级高优先级并转人工。

## 超时与破损

- 超过承诺时效未送达：可申请时效补偿，标准为订单金额 10%，单笔最高 20 元。
- 因延误导致变质：按品质赔付标准处理，**不与时效补偿叠加**。
- 外包装明显破损：建议当面拒收并拍照留存。
- 超时未取件导致变质：责任由用户承担，不在赔付范围。

## 边界

无物流记录但显示已发货、承运单号查不到：转人工核实。

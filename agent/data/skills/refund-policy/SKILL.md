# 退款与退货

## 先判断类型

- 生鲜商品保质期短，**原则上不支持无理由退货**；质量问题走赔付，不走退货。
- 未发货订单的取消与退款按取消政策执行，不属于品质赔付。
- 一次性全额赔付过的订单，不再支持二次品质申请。

## 处理步骤

1. 用户问退款到账：审核通过后一般 **1 至 3 个工作日原路退回**。
2. 超过 3 个工作日未到账：请用户提供**工单号**，转客服查询支付渠道处理进度。
3. 涉及优惠券：按券的规则退回或作废，以活动说明为准，不承诺折现。
4. 用户明确要求"不想要券、直接退钱"：超出自动规则，转人工协商。

## 边界

- 超过 48 小时提出的品质问题、金额有争议、要求全额赔付：转人工。
- 不要承诺具体到账时刻，只给"1 至 3 个工作日"的口径。
- 用户追问条款原文或"具体第几条"时，再读 `references/refund-policy.md`。

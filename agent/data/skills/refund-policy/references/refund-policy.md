# 退款与退货政策原文（节选）

> 来源：《生鲜电商售后服务政策（示例整理）》第 2 节；仅用于本项目演示。

## 2. 退款与退货

1. 生鲜商品因保质期短，原则上不支持无理由退货，质量问题按赔付处理而非退货。
2. 退款审核通过后一般 1 至 3 个工作日原路返回。
3. 超过 3 个工作日未到账的，可提供工单号由客服查询银行处理进度。
4. 一次性全额赔付的订单不支持再次申请品质问题。
5. 使用优惠券支付的部分按券的规则退回或作废，以活动说明为准。

## 常见追问

- 退款失败：提供工单号，由客服查询支付渠道状态。
- 发票抬头写错：可申请作废重开，需提供正确抬头与税号。
- 未发货订单：取消与退款按取消政策执行，不属于品质赔付。

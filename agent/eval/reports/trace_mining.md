## 三、怎么用这一池候选

1. 打开 `eval/datasets/trace_badcase_pool.jsonl`，逐条填三列：`expected_intent`（正确意图）、`expected_action`（正确的处置，比如「该转人工」「该追问订单号」）、`note`（一句话理由），填完把 `status` 改成 `labeled`；
2. 只想复核某一条的上下文时，用 `--print-transcript <session_id>` 原样回放整个会话；
3. 标好的行分成三路：意图写错的进意图训练集（`evolve_intent.py`），知识库答不出的进知识库补条目，检索没命中的进 reranker 迭代。

> 信号只负责「把可疑的挑出来」，不负责下结论。凡是这一池里被判为「没问题」的样本，正好可以用来收紧信号阈值（比如域外误杀率就是这么做出来的）。

复现命令：

```bash
python scripts/mine_traces.py --trace /mnt/d/生鲜售后agent/agent/data/trace
```
